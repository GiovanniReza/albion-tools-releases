# Albion Craft Planner — Descargas

Aplicación local para planificar fabricación y refinado en Albion Online, gestionar inventario y llevar un registro financiero.

**[Descargar la última versión para Windows](https://github.com/GiovanniReza/albion-tools-releases/releases/latest)**

## Instalar

1. Abre la última versión y descarga el archivo terminado en `-Setup.exe`.
2. Ejecuta el instalador y abre el acceso directo **Albion Craft Planner**.
3. La aplicación arranca en tu equipo y abre su interfaz en el navegador habitual.

Compatible con Windows 10 (1903+) y Windows 11 de 64 bits. No necesitas instalar Python ni Node. El primer inicio requiere Internet para descargar el catálogo; los precios e imágenes también necesitan conexión.

También se ofrece un ZIP: extrae **toda** su carpeta y ejecuta `AlbionCraftPlanner.exe`. `SHA256SUMS.txt` permite comprobar la integridad de las descargas.

## Actualizar y conservar tus datos

Cierra la aplicación y ejecuta el instalador de la nueva versión. Tus datos se conservan en `%LOCALAPPDATA%\AlbionCraftPlanner`, separados del programa. Cerrar la ventana de control detiene el servidor local.

## Sobre este repositorio

Este repositorio contiene únicamente instrucciones y paquetes de distribución. El proyecto fuente no está incluido. Los paquetes no contienen bases de datos personales del autor: cada usuario guarda sus propios datos localmente.

Las descargas son públicas y no requieren acceso al repositorio privado. No se conceden permisos de escritura a los visitantes; la gestión de versiones corresponde al propietario y a su automatización de publicación.
